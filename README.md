# Helonoia

Aset merek Helonoia: maskot monster, logo, dan ikon.

## Maskot & logo

`helonoia_monster.py` membangkitkan semua file maskot dan logo di folder ini:

```bash
python3 helonoia_monster.py
```

| File | Isi |
| --- | --- |
| `helonoia_monster.svg` | Maskot, latar transparan |
| `helonoia_monster_bg.svg` | Maskot, latar gelap `#120B1E` |
| `helonoia_logo.svg` / `.png` | Logo lengkap (maskot + tulisan), latar gelap |
| `helonoia_logo_transparent.svg` | Logo lengkap, latar transparan |

## Ikon kebiasaan

Folder `ikon/` berisi ikon untuk bagian "Empat kebiasaan kami". Semua ikon memakai grid 32×32, garis 2.4 dengan ujung dan sambungan membulat, serta `currentColor`, jadi warnanya mengikuti CSS induknya.

| File | Kebiasaan |
| --- | --- |
| `ikon/menyapa-duluan.svg` | Menyapa duluan (pintu terbuka) |
| `ikon/teliti-sampai-rewel.svg` | Teliti sampai rewel (tiga kali centang) |
| `ikon/janji-kecil-saja.svg` | Janji kecil saja (kecil tapi pasti) |
| `ikon/sedikit-aneh.svg` | Sedikit aneh (wajah monster) |
